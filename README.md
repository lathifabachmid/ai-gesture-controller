# 🤖 AI Gesture Controller

Real-time hand gesture recognition to control music playback and system volume using only your webcam.

## ✨ Features
- 🖐 Detects hand gestures in real-time
- 🎵 Controls Spotify: play/pause, next, previous track
- 🔊 Adjusts system volume
- 🎨 Clean UI overlay with gesture feedback

## 🕹 Gesture Map
| Gesture | Action |
|---|---|
| ✊ 0 fingers | Mute / Unmute |
| ☝ 1 finger | Next Track |
| ✌ 2 fingers | Previous Track |
| 🤟 3 fingers | Volume Up |
| 🖖 4 fingers | Volume Down |
| 🖐 5 fingers | Play / Pause |

## 🛠 Tech Stack
- Python
- OpenCV
- MediaPipe (via cvzone)
- PyAutoGUI

## ⚙️ Installation
pip install opencv-python cvzone mediapipe==0.10.9 pyautogui

## 🚀 How to Run
python gesture_controller.py
